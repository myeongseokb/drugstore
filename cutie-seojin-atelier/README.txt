큐티서진 CUTIE SEOJIN — 사이트 프로토타입

실행: ZIP 압축을 해제한 후 index.html을 Chrome, Edge, Safari 등 브라우저에서 여세요.
img 폴더는 index.html과 같은 위치에 두세요. 모든 CSS와 JS는 index.html 안에 포함되어 있습니다.

주요 시연 기능
- 히어로 4장 자동 슬라이드, 상품 분류/정렬/통합 검색, 찜, 장바구니
- 닉네임 기반 데모 가입, 신규 3,000P, 등급별 1/2/3/5% 적립, 포인트 사용, 주문 내역
- 모의 결제와 배송/픽업 선택 (픽업 가능한 상품만)
- 육아 커뮤니티 글, 상품 태그, 좋아요, 저장, 댓글
- 아이 정보/성장 기록, 키/몸무게, 기록에서 커뮤니티 공유, 연결된 상품 상세
- 육아 정보 및 가상 매장, 반응형 레이아웃

주의: 실제 카드 결제, 인증, 서버, 재고 관리, 공개 커뮤니티는 연결되어 있지 않습니다.
데이터는 브라우저 로컬 저장소에 저장됩니다. 실제 개인정보를 입력하지 마세요.
상품·가격·평점·매장·후기는 예시이며, 이미지들은 AI 생성 시안에서 분리하여 사용했습니다.
사이트 배포 전 상품 실사진·사업자 정보·보안·실제 회원 인증·PG·DB·매장 POS/재고·법적 약관 등을 별도로 구현해야 합니다.
